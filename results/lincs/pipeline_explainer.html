The transformation

Rank the profile's genes over the scored universe U:

rj = rankj / (|U| + 1)
t2j = Φ−1(rj)   directional
t1j = Φ−1(|2rj − 1| + (1 − max|2r − 1|)/2)   magnitude

Per edge (i,j) with mode mj and likelihood lj:

aj = mj lj t2j     bj = (1 − |mj|) lj t1j
S1i = Σj aj    S2i = Σj bj    σi = sign(S1i)

cij = ( aj + σi bj [S2i > 0] ) · ki    ki = wi / Σj lj, wi = √(Σj (lj/lmax)²)

Drug side: exact — condition-level VIPER has no null model, so Σj cij is the activity (verified, max |diff| 4.8e−07). Disease side: an allocation — msviper's permutation null cannot be replayed, so dij = cij · NESi/ESi.

4Reversal — the production score

79e_drug_reversal.py:285

The transformation

rev = −(D · s) / ‖s‖ = −Σi nesi · acti / ‖s‖

D = the drug's regulator activity, s = the disease NES vector. Each regulator's share is rev_contribi, and they sum to rev exactly.

Note what this multiplies: the total disease dysregulation by the total drug activity. It never asks whether the same genes are involved.

5rev_gene — the genes must match

79e3_window_contributions.py (COSINE=1)

The transformation

rev     = −Σi (Σj dij)(Σj Cij) / ‖s‖   a PRODUCT OF SUMS
rev_gene = −Σi Σj dij · Cij / ‖s‖   a SUM OF PRODUCTS

A regulator whose activity comes from genes orthogonal to the disease pattern has Σj dijCij ≈ 0 even when both totals are large — down-weighted by geometry, with no threshold and no tuned parameter.

Sign note (recorded because it was wrong once). di already carries the disease direction, since Σj dij = nesi. Multiplying by −nesi as well double-counts it and flips the sign. There is no nes factor in rev_gene.

6Opposition — per regulon, then per gene

79e3 (COSINE=1), D194/D195

The transformation

cos_contribi = ⟨di, Ci⟩ / (‖di‖ ‖Ci‖)
cos_termij = dij Cij / (‖di‖ ‖Ci‖)     Σj cos_termij = cos_contribi (exact to 1.6e−06 over 61,000 regulons)

Negative = the drug moves the very genes that account for that regulator's dysregulation, in the opposite direction.

This divides by ‖Ci‖ too, and that is the difference from rev_gene. D202 attributed the cosine score's whole ranking loss to it: rev/‖D‖ cost +0.004 AUC, adding the per-regulon normalisation cost −0.035. Scale-free per regulon means a regulon the drug never moved still contributes on the full ±1 scale.

7Programs — regulators that move together

58_regulator_modules.R → 79ai_programs.py / 79ak_drug_programs.py

The transformation

average-linkage clustering on 1 − |r|, cut at |r| ≥ 0.7
disease_scoreP = meani∈P nesi    drug_scoreP = meani∈P acti
oppositionP = − disease_scoreP · drug_scoreP / |disease_scoreP|

Disease programs cluster regulators over patients; drug programs over drugs, per window. 461 and 1,035 respectively.

Programs span only 27.4% of a cohort's regulators (clean ones 14.1%), which is why collapsing to them lost ranking power (D201).

8The reliability ceiling — what bounds every comparison

79e3 (SPLITHALF=1), D202

The transformation

R = mediani cosine( Ci(half A), Ci(half B) )

Split one drug's conditions in half, build each half's gene vector independently, and compare them. A drug against itself.

R = 0.531 overall (0.376 early, 0.590 late), and it is sample-size driven: 0.326 at 2 conditions → 0.793 at 10+ (Spearman +0.528). Nothing can match a vector better than it matches itself, so every similarity is reported as a fraction of R, never in absolute terms.
