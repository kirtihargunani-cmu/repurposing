The correction

A product of sums, or a sum of products

rev      = −Σi (Σj dij)(Σj Cij) / ‖s‖   multiplies the totals
rev_gene = −Σi  Σj dij · Cij    / ‖s‖   pairs the genes, one by one
d = disease gene contributions · C = drug gene contributions · both carry tfmode × likelihood

A regulator whose activity comes from genes orthogonal to the disease pattern has Σj dijCij ≈ 0 even when both totals are large — down-weighted by geometry, with no threshold and no tuned parameter.

Example: demoted

TGIF1 — disease NES +3.52, drug activity −1.17, so reversal scores it high. Gene cosine 0.016: the genes are orthogonal.

Example: promoted

KLF4 — totals say agreement, yet the genes oppose at −0.264. Reversal misses it entirely.

Recorded error: the first version multiplied by minus nes as well, double-counting the disease direction, because d already carries it — sum of d over j equals nes. Caught on the first smoke test when TAL1 read +0.29 by reversal and minus 0.03 by the new score.
