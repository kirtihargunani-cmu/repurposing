The ARACNe ESR1 regulon reads an ESR1 knockdown in the correct direction, which attributes the anti-estrogen inversion of the previous slide to drug biology rather than to the network.

On the Jaccard comparison: the within-cohort figure is the appropriate null. It is what the same inference procedure produces on data drawn from the same biology, so it measures the instability of the method itself. Comparing cross-tissue overlap against zero would overstate the result; comparing it against 0.552 is the conservative framing. On the knockdown benchmark: an AUC of 0.55 to 0.63 is modest in absolute terms and should be presented as such. The benchmark is also too thin to support per-transcription-factor decisions — one to five signatures per factor, and ARACNe against CollecTRI gives a paired p of 0.6. It is therefore reported and has never been used to select a regulon set for a given factor. An earlier proposal to do so would have dropped 143 factors on noise. On the ESR1 case specifically: this is the single most useful result on this slide, because it converts an apparent defect into an interpretable finding. Under anti-estrogens, GATA3 and FOXA1 rise, which the regulon reads as increased ESR1 programme activity. The network is behaving correctly; the compound's late-timepoint effect is genuinely in that direction. Consequence for the pipeline: per-cohort networks are retained rather than one global network, and this result also predicts the transfer limitation measured later — regulator-level quantities do not carry across cohorts.
