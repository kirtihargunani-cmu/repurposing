Imputing a missing timepoint window: the overlap is too thin

  • Most drugs are scored in a single window: only 939 drugs (4,128 rows) carry both; 13,332 rows carry one.
  • The target is noisy — the median both-row rests on one condition per window, below any predictor's reach.
  • Train ≠ apply: both-window data spans 14 cohorts; the rows to impute span 29 — extrapolation by construction.
  • "Early ≈ late" is weak (37% sign-discordant), and a continuous curve is impossible — only 196 pairs have ≥2 dose-fittable timepoints.
  • Decision: a pre-registered test with acceptance fixed before fitting; until it clears, a missing window stays unknown, not guessed.
