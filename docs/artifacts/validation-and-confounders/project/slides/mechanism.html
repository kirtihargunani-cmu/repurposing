This corrects an earlier reading of mine. I had treated ~1% cross-tissue regulon overlap as ARACNe failing to reproduce itself; the same-tissue resample control shows the floor is ~0.55, so the low cross-tissue number is biology (context-specific rewiring), which actually validates the per-cohort design. The separate, firmer limit is causal: co-expression cannot encode direction/inhibition however reproducible it is, so we read regulator activity, not a drug→target→regulator→gene mechanism.
